## 📚 Catálogo de Atividades

| Arquivo | Tema / Projeto | Tecnologias e Conceitos Abordados |
| :--- | :--- | :--- |
| **`Atividade09_03.zip`** | Página de Perfil Pessoal (`perfil.html`) | Estruturação semântica HTML5, seletores CSS3 (`css/estilo.css`), tipografia e estilização de seções. |
| **`Exercicio30_03.zip`** | Layouts e Box Model (`index.html` + `style.css`) | Posicionamento de elementos, margens, preenchimentos (*padding*), bordas e alinhamento visual. |
| **`atividade 04.05.zip`** | Estruturação e Componentes de Página | Criação de seções responsivas, listas estruturadas, tabelas e navegação interna. |
| **`atividade 18.05.zip`** | Formulários e Interatividade Visual | Campos de formulário HTML5, estados de foco/hover e organização de containers. |
| **`bootstrap.zip`** | Catálogo Temático (*Clash Royale Cards*) | Uso do framework **Bootstrap** com sistema de *grid* responsivo, *cards* de personagens (`Cavaleiro`, `Mini P.E.K.K.A`, `Mineiro Bombado`, `Pescador`) e CSS customizado. |
| **`Prova 1.zip`** | Avaliação Prática 1 + Guia Web | Projeto avaliativo integrando HTML5 e CSS3 (`index.html`, `estilo.css`), acompanhado do material de referência `guia_completo_web.pdf`. |

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**: `header`, `nav`, `main`, `section`, `article`, `footer`, formulários e tabelas.
- **CSS3**: *Box Model*, *Flexbox*, *Grid Layout*, variáveis, pseudo-classes e responsividade (*Media Queries*).
- **Bootstrap 5**: Sistema de colunas, *cards*, botões e utilitários de espaçamento.

---

## 🚀 Como Visualizar os Projetos

1. Clone este repositório:
   ```bash
   git clone https://github.com/grilocaio/atividades_web.git
   ```
2. Extraia o arquivo `.zip` da atividade desejada.
3. Abra o arquivo `index.html` (ou `perfil.html`) diretamente em qualquer navegador web ou utilizando a extensão **Live Server** no VS Code.
